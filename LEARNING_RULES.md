# Learning Rules

AI should accelerate learning without replacing the process of understanding.

## Core rules
1. Attempt problems independently before asking for solutions.
2. Ask for hints before asking for full answers.
3. Never accept generated code without understanding it.
4. Ask AI to explain execution step by step.
5. Validate AI-generated solutions with tests and reasoning.
6. Understand time and space complexity independently.
7. Use AI to challenge thinking, not simply confirm it.
8. Use AI for code review, debugging, and alternative approaches.
9. Implement important algorithms and systems from scratch.
10. Complete independent exercises regularly to verify real mastery.

## Recommended workflow
Attempt -> Hint -> Implement -> Test -> Review -> Understand internals -> Explain independently -> Document.
