# Engineering Mastery

A personal engineering curriculum, technical laboratory, and learning tracker for long-term mastery in software engineering, systems, infrastructure, data, and AI-assisted development.

## Mission
This repository exists to build strong technical foundations across the full engineering stack: algorithms, systems, Linux, networking, architecture, and AI-assisted workflows.

## Learning philosophy
- Learn from first principles.
- Implement from scratch when it sharpens understanding.
- Validate understanding with tests, notes, and independent explanations.
- Use AI as a tutor, reviewer, and accelerator without outsourcing reasoning.
- Keep a consistent daily practice loop and track progress over time.

## Daily learning routine
- Study one focused concept or topic.
- Practice with diagrams, notes, and implementation exercises.
- Solve related problems or coding challenges.
- Validate understanding in the terminal or with tests.
- Log the session in [DAILY_TRACKER.md](./DAILY_TRACKER.md).

## Weekly rotation
- Review one major topic per week.
- Track progress in [PROGRESS.md](./PROGRESS.md).
- Write a weekly reflection in [WEEKLY_REVIEWS.md](./WEEKLY_REVIEWS.md).
- Revisit weak areas and update gaps in the knowledge base.

## AI usage rules
See [LEARNING_RULES.md](./LEARNING_RULES.md) for the working principles and workflow.

## Start a new learning session
1. Open the relevant topic README.
2. Review the roadmap and mastery checklist.
3. Work through the stage that matches your current level.
4. Record what you studied in the daily log.
5. Commit a meaningful work product when the session adds value.

## Commit and documentation habits
- Keep a meaningful commit after each major learning session.
- Update the relevant topic README when you deepen understanding.
- Maintain [PROGRESS.md](./PROGRESS.md) and [DAILY_TRACKER.md](./DAILY_TRACKER.md) regularly.
- Keep problem solutions and notes organized under the relevant topic folders.
