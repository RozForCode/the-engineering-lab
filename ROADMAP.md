# Roadmap

This roadmap is intentionally long-term and adaptive.

## Phase 1: Foundations
- Data structures and algorithms fundamentals
- Complexity analysis and problem-solving patterns
- Number systems, memory, and computer architecture
- Linux basics and terminal workflow mastery

## Phase 2: Systems and infrastructure
- Operating systems, concurrency, networking, and HTTP
- Docker, cloud infrastructure, and distributed systems
- Security, networking protocols, and production systems understanding

## Phase 3: Engineering depth
- OOP, functional programming, design principles, and patterns
- APIs, databases, architecture, and testing
- Scalability, reliability, and system design practices

## Phase 4: Applied engineering and AI
- AI-assisted coding, prompting, and agentic workflows
- Practical labs across algorithmic and systems domains
- Repeated implementation of important systems from scratch
