# SQL Theoretical Questions

This folder is dedicated to medium-to-hard conceptual SQL questions that test reasoning, not just syntax.

## Purpose
These questions are designed to help you think like a database engineer and SQL problem solver. They focus on:
- query semantics
- execution order
- database internals
- optimization trade-offs
- correctness under edge cases
- real-world reasoning about relational systems

## How to use this folder
- Read each question carefully.
- Explain your answer before writing SQL.
- Focus on correctness, edge cases, and trade-offs.
- Discuss how a database engine might evaluate the query internally.

## Typical themes
- SQL execution order and evaluation rules
- NULL behavior and predicate truth tables
- Join semantics and loss of rows
- Aggregation boundaries and grouping behavior
- Window function semantics
- Indexing and scan strategy trade-offs
- Query optimization and database cost estimation
- Design choices for correctness and performance

## Suggested practice method
1. Attempt to answer without external notes.
2. Write a short but precise explanation.
3. Compare with a real execution plan or another approach.
4. Revisit weak areas and sharpen the mental model.
