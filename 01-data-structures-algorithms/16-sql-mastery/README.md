# SQL Mastery

SQL is not a side topic. It is a core engineering skill for data work, backend systems, analytics, and product intelligence.

## A. Topic overview
SQL is the language used to ask questions of structured data. To become strong at SQL, you need both syntax fluency and an understanding of how the database evaluates and optimizes queries.

## B. Learning objectives
- Write correct SELECT statements with filtering, sorting, joins, and aggregation.
- Handle NULLs, duplicates, and conditional logic with precision.
- Understand the difference between logical query structure and execution order.
- Use window functions, subqueries, CTEs, and set operations confidently.
- Optimize queries using indexes, execution plans, and database internals.

## C. Prerequisites
- Basic understanding of tables, rows, columns, and relational data.
- Familiarity with programming concepts such as iteration and data transformation.

## D. Detailed learning roadmap
### Stage 1: SQL foundations
- SELECT, WHERE, ORDER BY, DISTINCT, LIMIT
- Conditionals, NULL handling, and data types
- Basic joins and set thinking

### Stage 2: Intermediate analytics
- Aggregation, GROUP BY, HAVING, subqueries, CTEs
- Window functions and ranking logic
- Date, string, and deduplication patterns

### Stage 3: Advanced database reasoning
- Recursive CTEs, partitioning, and query execution order
- Indexes, B-trees, EXPLAIN, and query optimization
- Common interview problems and analytical use cases

## E. Under-the-hood knowledge
- Understand table scans, index lookup, join algorithms, and cost estimation.
- Learn how ORDER BY, GROUP BY, and window calculations are performed.
- Study how database engines evaluate queries logically and physically.

## F. Practical exercises
- Beginner: write simple SELECT queries and aggregate summaries.
- Intermediate: solve join, ranking, and retention challenges.
- Advanced: optimize real world queries and explain execution choices.

## G. Interview preparation
- Practice second-highest salary, top-N, consecutive dates, retention, and cohort queries.
- Explain the query strategy before writing it.
- Review edge cases such as NULLs, duplicates, and partition boundaries.

## H. Mastery checklist
- [ ] I can explain SQL execution order.
- [ ] I can write joins and aggregations correctly.
- [ ] I can use window functions to answer analytical questions.
- [ ] I can reason about optimization and indexes.

## I. Mastery assessment
### Level 1: Foundational understanding
I can read and write basic SQL and explain a few core patterns.

### Level 2: Proficient implementation and application
I can solve common interview and business dataset tasks with joins, aggregates, and window functions.

### Level 3: Deep technical mastery
I can explain query processing, optimize execution, and reason about database behavior under pressure.
